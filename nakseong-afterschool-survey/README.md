# 낙성초 방과후학교 인식 설문

초3~6 방과후 수강생을 대상으로 한 설문의 도구 모음이다. 학생은 QR로 Google 설문지에 답하고, 응답은 Google 시트에 쌓이며, 교원용 대시보드와 학부모·학생 공유용 PDF로 결과를 본다.

실제 학생 응답과 이름은 이 저장소에 올리지 않는다. `sample/`의 데이터는 모두 무작위로 만든 가상 응답이다.

## 설문이 답하려는 질문

1. 방과후 시간 자체를 어떻게 느끼는가 (a1), 싫다면 피로(a2) 때문인가 공부 시간이라는 인식(a3) 때문인가
2. 수업이 싫은 것인가, 방과후 자체가 싫은 것인가 (a1 × 수업 경험 → 학생 유형)
3. 수업에 대한 불만이 프로그램 때문인가 강사 때문인가 (활동 점수 × 선생님 점수, c1)

## 폴더

| 경로 | 내용 |
|---|---|
| `form/설문지만들기.gs` | 응답 시트의 Apps Script에 붙여 한 번 실행하면 설문지를 만들고 시트에 연결한다 |
| `dashboard/index.html` | 교원용 대시보드(Claude Data 아티팩트)의 페이지 원본. 모든 계산식이 들어 있다 |
| `build_pdf.js` | 학부모·학생 공유용 PDF 생성기 |
| `build_qr.js` | 교실용 QR 안내장(A4 1쪽) 생성기. `node build_qr.js <설문 주소> out/QR안내장.pdf` |
| `docs/build_guide_hwpx.py` | 교사용 문항 안내서(HWPX) 생성기. `pip install python-hwpx` 후 `python3 docs/build_guide_hwpx.py out/문항안내.hwpx` |
| `sample/` | 가상 응답. 응답 시트의 `students`, `responses` 탭과 같은 형식 |

## 문항

공통(학생당 1회): 학년, 이름(필수, 개별 상담용), a1 방과후 시간이 좋아요, a2 남아 있는 것이 힘들어요, a3 공부 시간처럼 느껴져요. 이름은 시트의 `이름` 탭에만 모으고 대시보드와 공유 자료에는 넣지 않는다.

수업별(듣는 수업마다), 설문지에 나오는 순서:

| 번호 | 문항 | 영역 |
|---|---|---|
| q4 | 이 수업이 있는 날이 기다려져요 | 흥미 |
| p1 | 이 수업에서 배우는 활동 자체가 재미있어요 | 프로그램 |
| q5 | 내가 직접 해 보는 활동이 많아요 | 활동 참여 |
| q6 | 몰랐던 것을 알게 되거나 못했던 것을 할 수 있게 되었어요 | 성장 |
| q7 | 선생님 말씀이 알아듣기 쉬워요 | 강사 |
| t2 | 선생님은 우리를 친절하게 대해 주세요 | 강사 |
| q8 | 이 수업 내용은 나에게 어땠나요? (너무 어려워요 ~ 너무 쉬워요, 5단계) | 프로그램 |
| q9 | 내년에도 이 수업을 또 듣고 싶어요 | 재수강 의향 |
| q10 | 이 수업 시간은 길게 느껴져요 | 역문항(점검용) |
| q11 | 나는 이 수업이 마음에 들어요 | 전반 만족(타당도 기준) |
| q12 | 가장 좋았던 것이나 기억에 남는 장면 | 서술 |
| c1 | 바뀌었으면 하는 것을 모두 골라 주세요 | 선택형(6개 보기) |
| q13 | 고른 까닭이나 바라는 점 | 서술 |

응답 보기: ⭕⭕ 아주 그래요 5 / ⭕ 그래요 4 / 🔺 보통이에요 3 / ❌ 아니에요 2 / ❌❌ 전혀 아니에요 1. 웃는 얼굴 대신 ○△✕를 쓴 것은 "지루할 때가 많아요" 같은 문항에서 표정이 뜻과 어긋나기 때문이다.

## 응답 시트 형식

`students`: `rid, grade, a1, a2, a3`
`responses`: `rid, program, q4, q5, q6, q7, q8, q9, q10, q11, p1, t2, q12, q13, c1, q8_level`
`이름`(시트 전용): `rid, grade, name`

- 점수는 1~5 원점수(역채점 전), 무응답은 빈칸
- `program`: art / unicycle / samul / guitar / violin
- `c1`: 고른 보기를 쉼표로 이은 글
- `q8`: 딱 알맞아요 5, 조금 어려워요·쉬워요 3, 너무 어려워요·쉬워요 1. `q8_level`: −2 너무 어려움 ~ +2 너무 쉬움
- 설문지의 이름 문항은 시트와 연결한 뒤에 넣어 응답 시트의 맨 끝 열에 들어간다. 다른 열 위치는 그대로다

## 계산 규칙

- 역채점 `q10_r = 6 − q10`, 환산 점수 `(평균 − 1) ÷ 4 × 100`
- 수업 경험 = q4, q5, q6, q7, q8, q9, q10_r 평균(4문항 이상 답한 응답). 학생의 수업 경험은 그 학생이 들은 수업의 평균
- 학생 유형: a1 4~5 → 경험 3.5 이상 만족형 / 미만 프로그램 불만형. a1 1~2 → 경험 3.5 이상 막연한 거부감형 / 미만 전반 불만형. a1 3은 중립
- 프로그램 대 강사: 활동 점수 = (p1 + q8) ÷ 2, 선생님 점수 = (q7 + t2) ÷ 2, 각각 3.5 기준으로 네 유형
- 점검 플래그(기본 제외): 모순(q4 ≥ 4 이고 q10 ≥ 4, 또는 q4 ≤ 2 이고 q10 ≤ 2), 일자 응답(q4~q11 6개 이상이 모두 같은 값)
- 신뢰도·타당도: 7문항 Cronbach α(기준 .70), 수업 경험과 q11의 피어슨 r(기준 .60)
- 익명성: 학년×수업 수강생 3명 미만인 칸의 점수와 개방형 응답은 표시하지 않는다
- 해석(확정): 중심 숫자는 "몇 명 중 몇 명이 그래요 이상(4~5)". 환산 점수는 교원용 보조이며 62.5 이상 긍정 / 37.5~62.5 보통 / 37.5 미만 부정(경계는 응답 보기 사이의 중간값). 응답 5건 미만은 색 없이 인원만 본다

## 공개 범위

| | 교원용 대시보드 | 공유용 PDF |
|---|---|---|
| 방과후 시간에 대한 인식(a1~a3) | 싣는다 | 싣는다 (학년은 3·4 / 5·6 두 묶음) |
| 수업별 결과 | 싣는다 | 싣지 않는다 |
| 강사 관련(q7, t2, c1의 선생님 보기) | 싣는다 | 싣지 않는다 |
| 개방형 원문 | 대표 의견만 | 싣지 않는다(분류 건수만) |

## 공유용 PDF 만들기

Node.js와 Playwright(Chromium)가 필요하다.

```bash
npm install
```

```bash
npm run pdf:sample
```

실제 응답으로 만들 때는 시트의 두 탭을 내려받아 `data/`에 두고(저장소에 올라가지 않는다) 실행한다. `responses`는 JSON 배열이어야 한다(c1에 쉼표가 들어가기 때문).

```bash
node build_pdf.js data/students.csv data/responses.json out/낙성초_방과후_설문결과.pdf
```

`photos/` 폴더에 사진을 넣으면 3장까지 2쪽에 실린다. 사진도 저장소에 올라가지 않는다.

## 아직 정하지 않은 것

- 설문이 끝난 뒤 응답 시트의 students·responses 탭 내용을 대시보드와 공유용 PDF에 한 번에 반영하기(실시간 연결은 하지 않기로 함)
- PDF의 "학교에서 이렇게 할게요" 칸 내용
- 대시보드의 "차년도 반영 요약" 영역(보류). 만들 때는 판단 기준을 결과를 보기 전에 정한다
